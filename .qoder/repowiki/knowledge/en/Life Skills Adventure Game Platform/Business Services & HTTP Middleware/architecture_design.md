Two sibling sub-packages with a one-way dependency from middleware to shared utilities: `backend/services/` holds stateless business units — `ai-service.js` calls an external AI endpoint with abortable fetch and falls back to a deterministic `localFallback` when `env.AI_ENABLED` is off; `otp-service.js` generates, hashes (bcrypt), stores, verifies, and reissues 6-digit OTPs via the `OtpCode` model and delegates transport to `email-service.js` (nodemailer, dev-mode console logging when SMTP is unset); `game-engine.js` orchestrates `GameSession`/`Scenario`/`AiInteraction` models, computes per-player metrics, builds a context object, and delegates decision-making to `ai-service.makeGameDecision`. `backend/middleware/` exports composable Express middlewares: `authMiddleware` decodes JWT cookies or Bearer headers, loads the user with a `PlayerProfile`, and enforces token versioning; `adminMiddleware` gates routes by `req.user.role === 'admin'`; `validate` wraps Joi schemas against `body`/`query`; `security` injects request IDs, rejects MongoDB-style unsafe keys (`$`, `.`), and exposes three `express-rate-limit` instances (`writeLimiter`, `authLimiter`, `otpLimiter`) plus a JSON body size cap; `error-handler` normalizes Sequelize errors into `AppError`-based responses and logs structured errors with `requestId`. All modules depend on `../config/env`, `../config/logger`, `../models`, and `../utils/app-error` — no cross-imports between services and middleware.
