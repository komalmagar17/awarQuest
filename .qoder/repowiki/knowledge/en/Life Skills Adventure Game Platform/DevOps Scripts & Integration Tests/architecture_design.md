Two distinct subdirectories under `backend/` with no shared code between them:
- `scripts/` contains standalone Node CLIs invoked via `node scripts/<file>.js`. Both `grant-admin.js` and `seed-scenarios.js` bootstrap by calling `connectDatabase()` from `../config/db`, import Sequelize models (`User`, `Scenario`) from `../models`, and close the connection on completion. `grant-admin.js` is an admin utility that finds a user by username or email and sets `role = 'admin'`; `seed-scenarios.js` defines an embedded `MISSIONS` array of life-skills scenarios and upserts them into the `Scenario` table keyed by `slug`, making it idempotent.
- `test/game-flow.test.js` is a self-contained integration smoke test that does not use a test runner — it runs directly with `node test/game-flow.test.js`. It targets a live API at `http://localhost:5001` (overridable via `API_URL`), performs a register → login → OTP verify → challenge start → clue collection → action → complete → progress submit → scores summary flow, and uses `node:assert/strict` to assert status codes and response shapes.
