Single-package FastAPI application under `app/` with four cohesive modules: `main.py` defines the FastAPI app, mounts `/health` and `/v1/decision` endpoints, and enforces request authentication via an HMAC token header (`X-AI-Service-Token`) validated against a configured secret. `config.py` uses Pydantic `BaseSettings` (with `.env` loading) to expose `gemini_api_key`, `gemini_model`, `ai_service_token`, `ai_port`, and `ai_log_level`. `schemas.py` centralizes all request/response models (`DecisionRequest`, `AIDecision`, `DecisionResponse`, plus enums like `AIAction` and `Difficulty`) using `extra='forbid'` for strict validation. `provider.py` implements an `AIProvider` ABC with two concrete strategies: `GeminiProvider` (configured via `google.generativeai` with JSON response schema enforcement) and a built-in `deterministic_decision` function used as a fallback when no provider is available or the LLM call times out after 5 seconds. `build_provider(settings)` selects the active strategy at runtime, enabling seamless hot-swap between gemini and deterministic modes. The service is containerized via a `Dockerfile` running uvicorn on port 8001.
