The root composes three runtime services via `docker-compose.yml`: a `postgres` database, a `ai-service` (Python/FastAPI) built from `backend/ai-service`, and the main `api` (Node/Express) built from `backend`. The API depends on both Postgres and the AI service, communicating over HTTP using a shared HMAC token (`AI_SERVICE_TOKEN`) defined in `.env.example`. A lightweight `simple-server.js` at the repo root serves the static frontend assets under `backend/public` for local development. Cross-cutting concerns—database connection, logging, resource catalogues, JWT secrets, CORS origins, SMTP settings, and guest-play toggles—are centralized in `shared_config` and injected into every child module through validated environment variables, so each child remains decoupled while sharing one source of truth for configuration.
